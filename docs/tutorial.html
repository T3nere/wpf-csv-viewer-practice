WPF練習教材 v5：CSVビューアを作る

.NET Framework上のWPFで、TextFieldParserを使ってCSVを読み込み、表示するアプリを7ステップで作ります。各ステップは「知識 → 演習 → 解答例」の順です。解答は先に見ず、まず自分で書いてみてください。

最終的に作るもの

  • CSVを読み込み、先頭6列だけをDataGridに表示する（7列目以降は捨てる）
  • 数値（半角の整数・小数・負数）以外が1つでもあればエラーメッセージを出し、読み込まない
  • チェックボックスがオンの間、DataGridをグレーアウトする
  • OK / Cancelボタンを置く。CSVを1度も読み込めていない間はOKを押せない

環境Visual Studio 2022、.NET Framework 4.8の「WPFアプリ(.NET Framework)」。プロジェクト名は CsvViewer。

ステップ2：TextFieldParserでCSVを読む

知識

  • OpenFileDialog.ShowDialog() は bool? を返し、「開く」を押したときだけ true です。
  • TextFieldParser は IDisposable なので using ブロックで囲みます（C# 7.3では using (…) { } の形）。
  • ReadFields() は1行を分割済みの string[] で返します。EndOfData が true になるまで繰り返します。
  • .NET Frameworkでは Encoding.GetEncoding(932)（Shift_JIS）が標準で使えるため、Encoding.RegisterProvider は不要です。
設定意味この教材での値
TextFieldType区切り式か固定幅かFieldType.Delimited
SetDelimiters(",")区切り文字（必須。未設定だと例外）","
TrimWhiteSpace各セルの前後の空白を除くか（既定true）true（" 34" → "34"）
HasFieldsEnclosedInQuotes"1,000" のような引用符を解釈するか（既定true）true
private static List<string[]> ReadCsv(string path)
{
    var rows = new List<string[]>();
    using (var parser = new TextFieldParser(path, Encoding.GetEncoding(932)))
    {
        parser.TextFieldType = FieldType.Delimited;
        parser.SetDelimiters(",");
        parser.TrimWhiteSpace = true;
        parser.HasFieldsEnclosedInQuotes = true;

        while (!parser.EndOfData)
        {
            string[] f = parser.ReadFields();
            if (f != null) rows.Add(f);
        }
    }
    return rows;
}
行番号のために parser.LineNumber を使いたくなりますが、最終行を読み終えた後は -1 を返すなど扱いにくいので、この教材では読み込んだ行を自分で数えます。ただし引用符が壊れた行の MalformedLineException.LineNumber は、ステップ7のとおりそのまま使えます。

ステップ3：DataGridに表示する（6列固定）

知識

  • DataGrid の ItemsSource に「行を表すオブジェクトのコレクション」を渡すと、1要素が1行として表示されます。ItemsSource に代入しない限り、何も表示されません。読み込んだデータを変数に入れただけでは画面は変わりません。
  • 列の作り方は2通りあります。AutoGenerateColumns="True"（既定）はプロパティ名から自動生成し、False にして DataGrid.Columns に DataGridTextColumn を書けば、ヘッダ名・幅・並び順を自分で決められます。列が固定ならこちらです。
  • Binding="{Binding C1}" は「行オブジェクトの C1 プロパティを表示する」という意味です。バインディングできるのはプロパティだけで、フィールド（public double C1;）は表示されません。{ get; set; } を付けます。
  • x:Name は型名（DataGrid）と別の名前にします。同じ名前でも動きますが、DataGrid.ItemsSource が型のメンバーかインスタンスのメンバーか、読む人が迷います。ここでは CsvGrid とします。
  • 7列目以降は、行クラスに入れないことで捨てます。

行クラスのプロパティの型

型正確に扱える整数の範囲向いている場合
string無制限表示だけでよい。先頭ゼロを残したい
int / long約21億 / 約9.2×1018整数として並べ替え・計算したい
float約1,677万（224）この用途には不向き（精度が足りず、表示も 1.234568E+09 のようになる）
double約9×1015（253）X・Y・Zのような座標値。小数を扱う可能性がある

この教材では座標値を想定して double を採用します。入力は整数のみですが、15桁を超える数字は正確に保持できない点は覚えておいてください。

<DataGrid x:Name="CsvGrid" Grid.Row="1" IsReadOnly="True" AutoGenerateColumns="False">
    <DataGrid.Columns>
        <DataGridTextColumn Header="X1" Binding="{Binding C1}" />
        <DataGridTextColumn Header="Y1" Binding="{Binding C2}" />
        <DataGridTextColumn Header="Z1" Binding="{Binding C3}" />
        <DataGridTextColumn Header="X2" Binding="{Binding C4}" />
        <DataGridTextColumn Header="Y2" Binding="{Binding C5}" />
        <DataGridTextColumn Header="Z2" Binding="{Binding C6}" />
    </DataGrid.Columns>
</DataGrid>
internal class CoordinateData
{
    public double C1 { get; set; }
    public double C2 { get; set; }
    public double C3 { get; set; }
    public double C4 { get; set; }
    public double C5 { get; set; }
    public double C6 { get; set; }
}

// using System.Globalization; が必要
private static List<CoordinateData> BuildRows(List<string[]> rows)
{
    var list = new List<CoordinateData>();
    foreach (string[] f in rows)
    {
        list.Add(new CoordinateData
        {
            C1 = double.Parse(f[0], CultureInfo.InvariantCulture),
            C2 = double.Parse(f[1], CultureInfo.InvariantCulture),
            C3 = double.Parse(f[2], CultureInfo.InvariantCulture),
            C4 = double.Parse(f[3], CultureInfo.InvariantCulture),
            C5 = double.Parse(f[4], CultureInfo.InvariantCulture),
            C6 = double.Parse(f[5], CultureInfo.InvariantCulture)   // f[6]以降は使わない = 捨てる
        });
    }
    return list;
}
// 呼び出し側
CsvGrid.ItemsSource = BuildRows(rows);

ここでは検証をしていないので、数字以外のセルや6列未満の行があると例外で落ちます。ステップ4で検証と変換を ConvertAll にまとめ、この BuildRows は不要になります。

参考：列数が実行時に決まる場合

CSVごとに列数が違うときは、列をXAMLに書けないため、System.Data.DataTable を作って DefaultView を渡す方法が手軽です。AutoGenerateColumns="True" のままで、DataTable の列がそのままDataGridの列になります（System.Data の参照はWPFのテンプレートに最初から入っています）。今回の教材では使いませんが、総合演習2の出発点になります。

<DataGrid x:Name="CsvGrid" Grid.Row="1" IsReadOnly="True" AutoGenerateColumns="True" />
using System.Data;

private static DataTable BuildTable(List<string[]> rows)
{
    int colCount = rows[0].Length;   // 1行目の列数に合わせる（rowsが空でないことは検証済みとする）
    var table = new DataTable();
    for (int i = 1; i <= colCount; i++) table.Columns.Add("列" + i);

    foreach (string[] f in rows)
    {
        DataRow row = table.NewRow();
        for (int i = 0; i < colCount && i < f.Length; i++) row[i] = f[i];
        table.Rows.Add(row);
    }
    return table;
}
// 呼び出し側
CsvGrid.ItemsSource = BuildTable(rows).DefaultView;

この方式のときは、行クラス CoordinateData と固定の列定義は不要です。また、OkButton_Click の行数取得は、ステップ7の CsvGrid.Items.Count のままで動きます。

ステップ4：入力検証と変換（ConvertAll）

知識

  • 「読み込まない」を満たすため、処理を2段階に分けます。ReadCsv（分割だけ）→ ConvertAll（全行を検証しながら変換）。不正があれば FormatException を throw します。
  • throw すると、その場から最も近い try の catch まで処理が飛びます。catch の中で return すれば、ItemsSource への代入は実行されません。これが「表に触れない」仕組みです。
  • 検証は正規表現で行います。1文字ずつ判定するコードが「どう調べるか」を書くのに対し、正規表現は「文字列全体がどんな形か」を宣言します。
  • 前後の空白は TextFieldParser が除去済みです。空白のみのセルは空文字になり、パターンに当てはまらないのでエラーになります（空欄も同じ）。
  • 変換の double.Parse は、検証を通った後に CultureInfo.InvariantCulture を付けて呼びます。小数点を常に . として読む保証になります。

パターン ^-?[0-9]+(\.[0-9]+)?\z の読み方

部品意味
^文字列の先頭
-?- が0個か1個（? は「省略可能」）
[0-9]+0〜9のどれか1文字を1回以上（[ ] は「この中のどれか1文字」、+ は「1回以上」）
(\.[0-9]+)?「小数点 ＋ 数字1個以上」の塊が0回か1回。\. は小数点そのもの
\z文字列の末尾
落とし穴：(1) ^ と \z を外すと部分一致になり、abc12 が通ります。(2) . は正規表現では「任意の1文字」なので、小数点は \. と書きます。(3) \d は全角数字にもマッチするので [0-9] を使い、末尾は $（末尾の改行の手前にもマッチする）ではなく \z を使います。C#では @"..."（逐語的文字列）にしないと、バックスラッシュがC#のエスケープとして解釈されます。
private const int ColCount = 6;
private static readonly Regex NumberPattern = new Regex(@"^-?[0-9]+(\.[0-9]+)?\z");

private static bool IsNumber(string s)
{
    return NumberPattern.IsMatch(s);
}

private static List<CoordinateData> ConvertAll(List<string[]> rows)
{
    if (rows.Count == 0)
        throw new FormatException("データがありません。");

    var list = new List<CoordinateData>();
    for (int r = 0; r < rows.Count; r++)
    {
        string[] f = rows[r];
        if (f.Length < ColCount)
            throw new FormatException($"{r + 1}行目（空行を除く）：列数が{ColCount}未満です。");

        for (int c = 0; c < ColCount; c++)
            if (!IsNumber(f[c]))
                throw new FormatException($"{r + 1}行目{c + 1}列目（空行を除く）：数値として不正です。");

        list.Add(new CoordinateData { /* ステップ3のとおり C1〜C6 に Parse して代入 */ });
    }
    return list;
}
// 呼び出し側（using System; が必要）
List<string[]> raw;
List<CoordinateData> data;
try
{
    raw = ReadCsv(dlg.FileName);
    data = ConvertAll(raw);
}
catch (FormatException ex)
{
    MessageBox.Show(ex.Message, "読み込みエラー", MessageBoxButton.OK, MessageBoxImage.Error);
    return;   // ここで抜けるので、以降の ItemsSource 代入は行われない
}
CsvGrid.ItemsSource = data;
元のCSVの列数（7列目以降を含む）を表示したいときは raw[0].Length を使います。data は6列に切り詰めた後の形なので、元の列数の情報は残っていません。

ステップ5：チェックボックスでグレーアウト

知識

IsEnabled = false にするとコントロール（と子要素）が操作不能になり、灰色で表示されます。CheckBox のオン／オフは IsChecked（bool? 型）で取得できます。実現方法は2つあり、この教材の完成形は方法Bです。

方法A：イベント（コードビハインド）

<CheckBox x:Name="GrayCheck" Content="表をグレーアウト"
          Checked="GrayCheck_Changed" Unchecked="GrayCheck_Changed" />
private void GrayCheck_Changed(object sender, RoutedEventArgs e)
{
    CsvGrid.IsEnabled = GrayCheck.IsChecked != true;
}

方法B：DataTrigger（XAMLだけ）

{Binding IsChecked, ElementName=GrayCheck} は「別のコントロールのプロパティを参照する」データバインディングです。DataTrigger は、その値が True の間だけ Setter を適用し、外れたら自動で元に戻します。「戻す処理」を書かなくてよいのが利点で、MVVMにつながる考え方です。

<DataGrid x:Name="CsvGrid" Grid.Row="2" IsReadOnly="True" AutoGenerateColumns="False">
    <DataGrid.Columns> ... </DataGrid.Columns>
    <DataGrid.Style>
        <Style TargetType="DataGrid">
            <Style.Triggers>
                <DataTrigger Binding="{Binding IsChecked, ElementName=GrayCheck}" Value="True">
                    <Setter Property="IsEnabled" Value="False" />
                </DataTrigger>
            </Style.Triggers>
        </Style>
    </DataGrid.Style>
</DataGrid>
<CheckBox x:Name="GrayCheck" Content="表をグレーアウト" Grid.Row="3" />

ステップ6：OK / Cancelと「読み込み済み」状態

using System.Collections.Generic;
using System.Globalization;
using System.IO;
using System.Text;
using System.Text.RegularExpressions;
using System.Windows;
using Microsoft.VisualBasic.FileIO;
using Microsoft.Win32;

namespace CsvViewer
{
    internal class CoordinateData
    {
        public double C1 { get; set; }
        public double C2 { get; set; }
        public double C3 { get; set; }
        public double C4 { get; set; }
        public double C5 { get; set; }
        public double C6 { get; set; }
    }

    public partial class MainWindow : Window
    {
        private const int ColCount = 6;
        private bool _loaded = false;

        public MainWindow()
        {
            InitializeComponent();
        }

        private void LoadButton_Click(object sender, RoutedEventArgs e)
        {
            var dlg = new OpenFileDialog { Filter = "CSVファイル|*.csv|テキストファイル|*.txt" };
            if (dlg.ShowDialog() != true) return;

            List<string[]> raw;
            List<CoordinateData> data;
            try
            {
                raw = ReadCsv(dlg.FileName);   // 分割だけ
                data = ConvertAll(raw);        // 検証 + 変換。不正なら例外
            }
            catch (FormatException ex)
            {
                ShowError(ex.Message);
                return;
            }
            catch (MalformedLineException ex)
            {
                ShowError($"{ex.LineNumber}行目：CSVの形式が不正です。");
                return;
            }
            catch (IOException ex)
            {
                ShowError(ex.Message);
                return;
            }

            CsvGrid.ItemsSource = data;   // これを忘れると表示されない
            StatusText.Text = $"{Path.GetFileName(dlg.FileName)}（{raw.Count}行 / 1行目は{raw[0].Length}列）";
            _loaded = true;
            OkButton.IsEnabled = _loaded;
        }

        private static List<string[]> ReadCsv(string path)
        {
            var rows = new List<string[]>();
            using (var parser = new TextFieldParser(path, Encoding.GetEncoding(932)))
            {
                parser.TextFieldType = FieldType.Delimited;
                parser.SetDelimiters(",");
                parser.TrimWhiteSpace = true;
                parser.HasFieldsEnclosedInQuotes = true;

                while (!parser.EndOfData)
                {
                    string[] f = parser.ReadFields();
                    if (f != null) rows.Add(f);
                }
            }
            return rows;
        }

        private static List<CoordinateData> ConvertAll(List<string[]> rows)
        {
            if (rows.Count == 0)
                throw new FormatException("データがありません。");

            var list = new List<CoordinateData>();
            for (int r = 0; r < rows.Count; r++)
            {
                string[] f = rows[r];
                if (f.Length < ColCount)
                    throw new FormatException($"{r + 1}行目（空行を除く）：列数が{ColCount}未満です。");

                for (int c = 0; c < ColCount; c++)
                    if (!IsNumber(f[c]))
                        throw new FormatException($"{r + 1}行目{c + 1}列目（空行を除く）：数値として不正です。");

                list.Add(new CoordinateData
                {
                    C1 = double.Parse(f[0], CultureInfo.InvariantCulture),
                    C2 = double.Parse(f[1], CultureInfo.InvariantCulture),
                    C3 = double.Parse(f[2], CultureInfo.InvariantCulture),
                    C4 = double.Parse(f[3], CultureInfo.InvariantCulture),
                    C5 = double.Parse(f[4], CultureInfo.InvariantCulture),
                    C6 = double.Parse(f[5], CultureInfo.InvariantCulture)
                });
            }
            return list;
        }

        private static readonly Regex NumberPattern = new Regex(@"^-?[0-9]+(\.[0-9]+)?\z");

        private static bool IsNumber(string s)
        {
            return NumberPattern.IsMatch(s);
        }

        private static void ShowError(string message)
        {
            MessageBox.Show(message, "読み込みエラー", MessageBoxButton.OK, MessageBoxImage.Error);
        }

        private void OkButton_Click(object sender, RoutedEventArgs e)
        {
            int rows = CsvGrid.Items.Count;
            MessageBox.Show($"{rows}行を取り込みました。", "OK");
            Close();
        }

        private void CancelButton_Click(object sender, RoutedEventArgs e)
        {
            if (_loaded)
            {
                MessageBoxResult r = MessageBox.Show("読み込んだデータを破棄して閉じますか？", "確認",
                    MessageBoxButton.YesNo, MessageBoxImage.Question);
                if (r != MessageBoxResult.Yes) return;
            }
            Close();
        }
    }

役割担当この例では
View見た目。ロジックを持たないMainWindow.xaml（コードビハインドは DataContext の設定のみ）
ViewModel画面の状態と操作を、プロパティとコマンドで表すMainViewModel

コードビハインド版との対応

コードビハインド版MVVM版
LoadButton_Click など Click イベントICommand（RelayCommand）＋ Command="{Binding LoadCommand}"
StatusText.Text = …StatusText プロパティを変えると、PropertyChanged で画面が更新される
CsvGrid.ItemsSource = dataRows プロパティ ＋ ItemsSource="{Binding Rows}"
OkButton.IsEnabled = trueOkCommand の CanExecute（IsLoaded の値）。ボタンの有効・無効は自動
DataTrigger でグレーアウトIsGrayed プロパティ（チェックと双方向）と、そこから導く IsGridEnabled
MessageBox、OpenFileDialog、Close()IDialogService 経由、および CloseRequested イベント（ViewModelがUIの部品を直接呼ばないため）
ViewModelから MessageBox を直接呼ばないのは、ViewModelを画面なしでテストできるようにするためです（IDialogService の偽物を渡せば、LoadCommand の動作を自動テストできます）。

using System;
using System.Collections.Generic;
using System.ComponentModel;
using System.Runtime.CompilerServices;
using System.Windows.Input;

namespace CsvViewer
{
    // 値が変わったことを画面に知らせる仕組み
    public abstract class ViewModelBase : INotifyPropertyChanged
    {
        public event PropertyChangedEventHandler PropertyChanged;

        protected bool SetProperty<T>(ref T field, T value, [CallerMemberName] string name = null)
        {
            if (EqualityComparer<T>.Default.Equals(field, value)) return false;
            field = value;
            OnPropertyChanged(name);
            return true;
        }

        protected void OnPropertyChanged([CallerMemberName] string name = null)
        {
            PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(name));
        }
    }

    // ボタンの Click の代わりに、XAMLの Command="{Binding ...}" から呼ばれる
    public class RelayCommand : ICommand
    {
        private readonly Action _execute;
        private readonly Func<bool> _canExecute;

        public RelayCommand(Action execute, Func<bool> canExecute = null)
        {
            _execute = execute;
            _canExecute = canExecute;
        }

        public event EventHandler CanExecuteChanged;

        public bool CanExecute(object parameter) { return _canExecute == null || _canExecute(); }
        public void Execute(object parameter) { _execute(); }

        // 押せるかどうかの条件が変わったら呼ぶ（ボタンの IsEnabled が更新される）
        public void RaiseCanExecuteChanged()
        {
            CanExecuteChanged?.Invoke(this, EventArgs.Empty);
        }
    }
}
MainViewModel.cs 
using System;
using System.Collections.Generic;
using System.IO;
using Microsoft.VisualBasic.FileIO;

namespace CsvViewer
{
    public class MainViewModel : ViewModelBase
    {
        private readonly IDialogService _dialogs;
        private string _statusText = "未読み込み";
        private List<CoordinateData> _rows;
        private bool _isGrayed;
        private bool _isLoaded;

        public MainViewModel(IDialogService dialogs)
        {
            _dialogs = dialogs;
            LoadCommand = new RelayCommand(Load);
            OkCommand = new RelayCommand(Ok, () => IsLoaded);   // 未読み込みの間は押せない
            CancelCommand = new RelayCommand(Cancel);
        }

        public event EventHandler CloseRequested;   // 「閉じたい」とViewに頼む

        public string StatusText
        {
            get { return _statusText; }
            private set { SetProperty(ref _statusText, value); }
        }

        public List<CoordinateData> Rows
        {
            get { return _rows; }
            private set { SetProperty(ref _rows, value); }
        }

        public bool IsGrayed
        {
            get { return _isGrayed; }
            set { if (SetProperty(ref _isGrayed, value)) OnPropertyChanged(nameof(IsGridEnabled)); }
        }

        public bool IsGridEnabled { get { return !IsGrayed; } }

        public bool IsLoaded
        {
            get { return _isLoaded; }
            private set { if (SetProperty(ref _isLoaded, value)) OkCommand.RaiseCanExecuteChanged(); }
        }

        public RelayCommand LoadCommand { get; }
        public RelayCommand OkCommand { get; }
        public RelayCommand CancelCommand { get; }

        private void Load()
        {
            string path = _dialogs.OpenCsvFile();
            if (path == null) return;

            List<string[]> raw;
            List<CoordinateData> data;
            try
            {
                raw = CsvLoader.ReadCsv(path);
                data = CsvLoader.ConvertAll(raw);
            }
            catch (FormatException ex) { _dialogs.ShowError(ex.Message); return; }
            catch (MalformedLineException ex)
            {
                _dialogs.ShowError($"{ex.LineNumber}行目：CSVの形式が不正です。");
                return;
            }
            catch (IOException ex) { _dialogs.ShowError(ex.Message); return; }

            Rows = data;
            StatusText = $"{Path.GetFileName(path)}（{raw.Count}行 / 1行目は{raw[0].Length}列）";
            IsLoaded = true;
        }

        private void Ok()
        {
            _dialogs.ShowInfo($"{Rows.Count}行を取り込みました。");
            CloseRequested?.Invoke(this, EventArgs.Empty);
        }

        private void Cancel()
        {
            if (IsLoaded && !_dialogs.Confirm("読み込んだデータを破棄して閉じますか？")) return;
            CloseRequested?.Invoke(this, EventArgs.Empty);
        }
    }
}
